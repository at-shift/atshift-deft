# 0.5.0: atshift DEFT

Version: `0.5.0` (without an alpha suffix). This note includes historical local
verification evidence. Public source preparation uses a new repository,
`at-shift/atshift-deft`, without importing private repository history. GitHub
publication does not imply a WordPress.org release or production installation.

## Identity

- Product: **atshift DEFT**, optionally styled **atshift D.E.F.T.** in explanatory copy.
- Meaning: **Delegate Execution. Focus on Thinking.**
- Japanese message: 伝えることに専念する。あとの作業は、いつものAIに。
- WordPress slug/text domain: `atshift-deft`.
- Plugin entry: `atshift-deft/atshift-deft.php`.
- ZIP: `atshift-deft-0.5.0.zip`.
- Public source target: `at-shift/atshift-deft`. The original prototype repository remains private.

## Compatibility

This changes the installation identity, not the storage/protocol contract.
Preserve `sf_*` tables, options, post types, role keys and capabilities, private
storage paths, localStorage keys, JSON/schema identifiers, CSS selectors, MCP
tool names, REST/admin routes, OAuth issuer/resources/scopes, and scheduled hooks.
Only the three role display names change; no accounts or capabilities are reassigned.
Existing connections do not need reauthorization solely for this rename.

Back up the isolated site, deactivate Structured Fields Prototype, then install
and activate atshift DEFT. Keep the old plugin inactive; no uninstall/data removal
is needed. WordPress treats the new folder/main file as a separate plugin, not
an automatic in-place update. If the legacy plugin is still active (including
network activation), DEFT stops before loading the shared runtime and warns an
administrator; activation is rejected. This also prevents class/function
collisions regardless of plugin load order.

An automated distribution migration is not included. Multisite deployment and
real AI-provider end-to-end connections are not certified by this rename.
Name/trademark availability and WordPress.org slug allocation are not verified.

### Guide-First Onboarding

The first-use modal offers the guide download, not connection setup. The user
gives that one file to their AI. It guides the appropriate connection route,
verifies read-only live context, and offers an optional fictional sample once.
The sample saves a separate labeled private draft and previews it; no new
components, media transfer or publication is part of the exercise. Users can
skip, resume an existing draft or proceed directly to their original brief.
No separate sample file is needed. Passwords and tokens stay outside chat.
This is an AI instruction contract, not automatic client configuration or a new
server-side sample/publication permission. Real provider behavior remains unverified.
